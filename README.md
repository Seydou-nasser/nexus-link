# NexusLink

Alternative légère, rapide et 100 % locale à *Mobile connecté* de Windows.

## Structure du projet

- `desktop/` : Application PC **Tauri v2** (Backend en **Rust**, Frontend en **React + TypeScript + Tailwind CSS**).
- `android/` : Application mobile **Android Natif** (**Kotlin + Jetpack Compose**).
- `docs/` : Documentation technique et spécification du protocole réseau (`protocol-spec.md`).
